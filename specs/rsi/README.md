# RSI — Recursive Self-Improvement, Explained

A short course on the ideas behind Snake Arena's improvement loop, written for anyone
who can follow a high-school maths class. Read in order:

1. [What is RSI?](01-what-is-rsi.md) — the idea, the four-step loop, a little history.
2. [Worked examples](02-worked-examples.md) — nine small examples with real numbers;
   each maps to a module we build.
3. [Algorithms](03-algorithms.md) — from hill climbing to AlphaEvolve, in plain words,
   with sources and what Snake Arena uses.
4. [Pitfalls](04-pitfalls.md) — how self-improvement fools itself, and the rail for each.
5. [Glossary](05-glossary.md) — every term in one table.

**The one-line summary:** propose a change, test it fairly against the old version on
fresh games, keep it only if it's clearly better, save it, and repeat — and never let the
thing being improved control how it's judged.
